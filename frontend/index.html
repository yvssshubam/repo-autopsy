This Privacy Policy explains how Repo Autopsy handles information when you use the service.

1. Information We Collect

Repo Autopsy may process information that you voluntarily provide when using the service, including repository URLs and information necessary to analyze public repositories.

2. Repository Information

When you submit a public GitHub repository, the service may retrieve publicly available repository information such as file names, source code, metadata, dependencies, and repository structure for the purpose of analysis.

3. How Information Is Used

Information processed by Repo Autopsy is used to provide repository analysis, generate architectural insights, identify dependencies, and provide requested product features.

4. Data Retention

Repository analysis data may be temporarily stored while an analysis is being performed. Retention periods may change as the service develops.

5. Third-Party Services

Repo Autopsy may use third-party services such as GitHub APIs or infrastructure providers to provide the service.

6. Security

We take reasonable measures to protect information processed through the service. However, no internet service can guarantee absolute security.

7. Changes to This Policy

This policy may be updated as Repo Autopsy evolves.

8. Contact

For questions about this Privacy Policy, contact the Repo Autopsy team through the project's official repository.
